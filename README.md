# DK Design Kings

Web estática de presentación y personalización de prendas. No necesita instalar dependencias ni compilarse.

## Publicar con GitHub Pages

1. Abre esta carpeta en GitHub Desktop y confirma los cambios con un primer commit en la rama `main`.
2. Pulsa **Publish repository** y publica el repositorio como público. Los modelos 3D se incluyen en el proyecto; publícalos desde GitHub Desktop, no desde la web de GitHub, que limita las subidas individuales.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/(root)`, y guarda.
5. Cuando termine el despliegue, la web estará disponible en `https://<usuario>.github.io/<repositorio>/`.

La página principal es `index.html` y debe permanecer en la raíz del repositorio. GitHub Pages publica el sitio y sus archivos fuente; no subas datos privados.
